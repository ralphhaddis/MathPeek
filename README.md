# MathPeek

Native macOS clipboard LaTeX preview, built locally for this Mac.

## Use
1. Open `~/Applications/MathPeek.app`.
2. Copy text with `⌘C`, then press **`⌃⌥⌘L`** (or choose **Preview Clipboard** from the MathPeek menu bar menu, or trigger **Preview Clipboard in MathPeek** under **System Settings → Keyboard → Keyboard Shortcuts → Services → General**). Leave the preview panel open while copying new text to update it automatically.

The menu bar function symbol offers **Preview Clipboard** (`⌃⌥⌘L`), an **Auto Preview Copied Text** toggle, and **Quit MathPeek**. Auto preview is on by default while the preview panel is open; new general-clipboard text updates the panel and adds a history entry. Clipboard changes never open the panel on their own. Highlighting text alone is not an input path—Auto Preview ignores concealed/transient password-manager items (`org.nspasteboard.ConcealedType`, `TransientType`, `AutoGeneratedType`) and terminal copy-on-selection writes (such as iTerm2's default `CopySelection`). The most recent 40 renders remain in memory for the app session. The watcher can be paused from the menu. MathPeek does not write clipboard history to disk or replace clipboard contents automatically. The app does not automatically launch at login; opening ~/Applications/MathPeek.app starts it.

In the preview panel, `⌘R` refreshes from the clipboard, `⌘C` (or **Copy Source**) copies the latest input, `Esc` or `⌘W` (or Close) hides the panel, and `⌘Q` quits MathPeek. Clipboard changes do not reopen a hidden panel. The panel stays visible when switching apps. Use the scrollbar to review earlier formulas. The native material and monochrome image use system appearance.

## Build & Install
```bash
# Build only (outputs build/MathPeek.app)
/Applications/Xcode.app/Contents/Developer/usr/bin/python3 build.py

# Build, run renderer tests, install to ~/Applications/MathPeek.app, and relaunch
/Applications/Xcode.app/Contents/Developer/usr/bin/python3 build.py --test --install
```

## Files
- ARCHITECTURE.md: design, interaction contract, edge cases and research.
- Main.swift: native panel, menu, clipboard watcher and asynchronous job control.
- render.py: bounded local TeX worker.
- build.py: builds, ad-hoc signs, and optionally tests/installs/relaunches the app (`--test`, `--install`).
- check_render.py: real compiler regression checks.

## Dependencies
Uses BasicTeX, Homebrew Poppler, and Python from the selected Xcode developer directory. The build bundles that Python's Pillow package inside the app, so the renderer does not load user site packages. Install Pillow in the selected Python environment before building on another Mac.

## Verified
- Swift compilation and ad-hoc signing succeeded.
- All 25 real rendering/physics-macro/error/rejection cases in `check_render.py` passed.
- Pen-test hardening probes (`\^^` escapes, `\@@input`, `\pdfmdfivesum`, `\pdffilesize`, `\RequirePackage`, `\scantokens`, `\everypar`) were all rejected.
- The selection-free General Service (`Preview Clipboard in MathPeek`) is registered in the macOS Services database.
- The installed renderer passes with the app's exact Python environment and disabled user site packages.
- Clipboard watcher, global hotkey, and history scrolling need interactive QA on the desktop; the updated app is installed and running.
- Cancellation/resource-limit checks are recorded in the session report.

## Remaining interactive QA
Verify Escape, close, dragging, screen edges, multiple displays, full-screen Spaces, dark/light changes, VoiceOver, and Reduce Transparency on the actual desktop. These visual behaviors have not been independently observed yet.

This is a local prototype, not a notarized distributable app. Arbitrary TeX projects, external files, package installation and general prose-to-math extraction are out of scope. The renderer uses macOS `sandbox-exec`, which Apple has deprecated; rendering stops if that sandbox is unavailable. The sandbox narrows file and network access, but no software can guarantee zero vulnerabilities, especially in TeX and PDF parsing libraries.
